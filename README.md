# shot-prometheans

Public site for the Prometheans — the history-of-engineering group that runs sessions at the Society for the History of Technology's annual meeting and the Engineering Studies working group at the Consortium for History of Science, Technology and Medicine.

Plain static HTML and CSS. No build step, no dependencies. Run `python3 -m http.server` in this folder and visit `http://localhost:8000` to preview.

## Layout

```
index.html              Home
about/index.html        About the group
shot/index.html         SHOT annual conferences — year list
shot/2026/index.html    SHOT 2026 — seven sessions, eighteen papers
shot/2025/index.html    SHOT 2025 — four panels, fourteen presentations
chstm/index.html        Working group — session archive, 2023 onward
assets/style.css        The whole stylesheet
.nojekyll               Serve files as-is, no Jekyll processing
```

Every page carries the same four-item nav. When you add a page, add it to that nav in all of them.

## Adding a SHOT year

1. Copy `shot/2026/` to a new folder, e.g. `shot/2025/`.
2. Edit the sessions. The markup pattern per session is:

```html
<li class="session">
  <p class="when">Day DD Month &middot; HH:MM&ndash;HH:MM UTC</p>
  <h3>Session title<span class="badge">Workshop</span></h3>
  <ul class="papers">
    <li>
      <span class="who">Name <span class="aff">&mdash; Institution</span></span>
      <span class="paper">Paper title</span>
    </li>
  </ul>
</li>
```

The `<span class="badge">` is optional — use it only for a format that isn't a standard paper session. Session numbers are generated by CSS, so you never type or renumber them.

3. In `shot/index.html`, turn that year's `<li class="pending">` into the linked `<li>` form.

## Adding a working-group session

In `chstm/index.html`, add to the top of `<ol class="archive">`, under the right `<li class="yrmark">` year:

```html
<li>
  <p class="when">DD Month YYYY</p>
  <h3>Speaker or subject</h3>
  <p class="detail">What was discussed, with the book or paper in &lt;i&gt; tags.</p>
</li>
```

## Conventions

- All links are relative, so the site works under the `/shot-prometheans/` path GitHub Pages serves it from.
- SHOT times are given in UTC, as the virtual meetings are run.
- Presenters are listed as they appear in the SHOT programme.
- The working-group archive omits postponed and cancelled dates, and does not list upcoming sessions.
- The 2025 page follows the published Engineering Studies report rather than the draft programme: three scheduled presenters (Kochetkova, Casonato, Castro) do not appear in the report and are left out, and where a delivered title differed from the one in the programme, the report's title is used.

## Design

Palette and typography follow the SHOT website, read from its own computed styles:

| Token | Value | Used by SHOT for |
|---|---|---|
| `--navy` | `#09347A` | headings, links |
| `--orange` | `#F4911E` | logo mark, buttons, accents |
| `--ink` | `#2B3038` | body text |
| `--ink-soft` | `#6F7683` | secondary text |
| `--paper` | `#F3F8FB` | page background |
| `--surface` | `#FFFFFF` | content panels |

Headings are **Playfair Display** at regular weight (400), as SHOT sets them — free on Google Fonts, so it matches exactly.

Body text is **Mulish**, standing in for SHOT's **Proxima Nova**, which is a licensed Adobe font and cannot be served from a public repository. Mulish is the nearest free humanist sans; SHOT's own `helvetica, arial` fallbacks follow it in the stack. If the Society shares its Typekit kit, add the kit's stylesheet to each page and change one line in `assets/style.css`:

```css
--sans: proxima-nova, helvetica, arial, sans-serif;
```

Spacing runs on a 1.5 / 2.5 / 4 / 5 / 6.5 rem scale, and the only heavy rule on the page is the orange one under the masthead. Everything else is a hairline or plain space.

A dark appearance is included, derived from the same navy and orange. SHOT's own site has none; remove the two dark blocks at the top of the stylesheet if you would rather match it exactly.
